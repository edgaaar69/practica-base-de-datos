## Conclusión

Durante esta práctica aprendí los conceptos básicos de las bases de datos relacionales y el uso de SQL. Practiqué la creación de bases de datos y tablas, la inserción de registros mediante INSERT, las consultas mediante SELECT y WHERE, la modificación mediante UPDATE y la eliminación mediante DELETE.

También aprendí la importancia de utilizar WHERE al modificar o eliminar información para evitar afectar registros que no correspondan.
